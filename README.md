## 🧪 Дипломный проект

Эти проекты были выполнены во время обучения в школе автоматизации тестирования [QA.GURU](https://qa.guru/).

### 📱 [Mobile Tests — Wikipedia](https://github.com/ChukanovaEkaterina/Mobile-Tests-Wikipedia)

![Mobile Testing](https://img.shields.io/badge/MOBILE%20TESTING-1D4ED8?style=flat-square) · [Wikipedia Alpha для Android](https://www.mediawiki.org/wiki/Wikimedia_Apps/Team/Android/en)

Поиск и открытие статей, очистка поиска и проверка главного экрана Wikipedia. Запуск на Android через BrowserStack или локальный Appium.

**Стек** · Appium · Selenide · BrowserStack · OWNER

### 🛒 [Octagon Shop](https://github.com/ChukanovaEkaterina/OctogonShop-ui-test)

![Web UI](https://img.shields.io/badge/WEB%20UI-6D28D9?style=flat-square) · [octagon-shop.com](https://octagon-shop.com/)

Проверки формы регистрации интернет-магазина. В проекте показаны запуск через Jenkins и Selenoid, отчёты Allure и уведомления в Telegram.

**Стек** · Selenide · JUnit 5 · Jenkins · Allure TestOps

---

### 📚 [Book Club](https://github.com/ChukanovaEkaterina/Book-club-tests-API-UI)

![UI + API](https://img.shields.io/badge/UI%20%2B%20API-0F766E?style=flat-square) · [book-club.qa.guru](https://book-club.qa.guru/)

- **REST API** — регистрация, вход, выход и обновление профиля. Получение списка клубов, их создание, обновление и удаление. Создание, чтение, редактирование и удаление отзывов. Негативные сценарии проверяют обязательные поля, неверные данные входа, недействительные токены, права на удаление отзывов и оценки вне диапазона 1–5.
- **UI + API** — создание клуба через форму, поиск и просмотр клуба, отображение изменений и отсутствие удалённых клубов в поиске. Создание, редактирование и удаление своего отзыва через интерфейс, отображение изменений из API и проверка ограничений для другого пользователя.

**Стек** · REST Assured · Selenide · JUnit 5 · Allure
